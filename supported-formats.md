# Supported Formats

BWV scans the chosen folder for MP4, M4V, MOV, AVI, MKV, WebM, WMV, FLV, MPEG, MPG, TS, and MTS files. A supported extension only means the app will offer the file for processing; FFmpeg must still be able to decode its streams.

Watermarked copies are written as broadly compatible MP4 files with H.264 video and AAC audio.

Logo watermark files can be PNG, JPG, JPEG, or WebP. Transparent PNG artwork is usually the best choice for a clean logo overlay.
