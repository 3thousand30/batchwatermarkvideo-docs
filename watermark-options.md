# Watermark Options

## Text and logos

Use a text watermark, an image logo, or both together. Text is useful for an owner name, review notice, or copyright line. A logo can be PNG, JPG, JPEG, or WebP. When both are supplied, the app applies both with the same placement and appearance settings.

## Placement

Choose top-left, top-right, bottom-left, bottom-right, or centre. For normal delivery copies, **Fixed** keeps the mark in exactly that place throughout the video.

## Moving proof watermark

Select **Moving** to move the mark between the four safe corners every eight seconds. This is useful for review copies and proof footage because a crop that removes the mark in one segment will not remove it consistently across the full clip. It is a deterrent, not a replacement for access control or copyright enforcement.

## Opacity, text size, and margin

Start with 70% opacity, 36px text, and a 32px margin. Increase opacity for proof copies; lower it for subtle branding. Check a representative short output when your source videos have unusual dimensions or very high resolution.

## Frame preview

BWV uses a frame from the first supported video in the selected folder to show the current watermark. The preview updates after a short pause when you change text, logo, placement, opacity, text size, margin, or motion. Use **Original**, **Watermarked**, or **Split** to compare the rendered result before processing the full batch.
