# Getting Started

Download [Batch Watermark Video from Microsoft Store](https://apps.microsoft.com/detail/9P13V309MK2S), then open it from the Start menu.

1. In **Input folder**, select **Browse** and choose a folder containing videos. BWV scans that folder only, not its subfolders.
2. In **Watermark**, enter text, choose a logo file, or use both. Logo files can be PNG, JPG, JPEG, or WebP.
3. Choose one of the nine fixed placements for a stable branded copy, or select **Moving** for a proof watermark. Moving paths can be **Horizontal**, **Vertical**, **Diagonal** (a DVD-style bounce), or **Random** (a varied sequence of safe positions every four seconds).
4. Set opacity, text size, and edge margin. Review a short test output before a large batch.
5. In **Output**, accept the separate `watermarked` folder or browse to another destination. Add a suffix if you need one.
6. Select **Watermark videos**. The activity log records each completed, skipped, or failed video.

Watermarking creates MP4 copies. The source videos are not changed.
