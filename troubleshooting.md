# Troubleshooting

## No videos appear

Confirm the videos are directly inside the selected folder. BWV does not scan subfolders, and it only lists its supported video extensions.

## The watermark button is unavailable

Choose an input folder with at least one video, set a separate output folder, and provide watermark text, a logo, or both.

## A logo cannot be used

Choose an existing PNG, JPG, JPEG, or WebP image. For best results, use a transparent PNG logo with clear contrast.

## A file fails

Try a different source video first. Some files with a common extension contain damaged or uncommon streams that FFmpeg cannot decode. Ensure the output folder is writable and that there is enough free space for a new MP4 copy.

## The mark is too small or too subtle

Increase text size or opacity, or select Moving for proof copies. Test a short representative video before watermarking a large folder.
